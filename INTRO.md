# 简介文案 / Store copy

## GitHub About / 一句话

中文：把 dsh 的聊天记录、插件、设置和项目文件一键备份到本机或 WebDAV，需要时找回。

English: One-click backup and restore for DeepSeek Harness — chat history, plugins, settings and project files, on disk or WebDAV.

## 简短简介 / Short

中文：鲸鱼娘备份把 dsh 的聊天记录、插件、插件数据、设置和可选的项目文件打包成带 SHA-256 校验的归档，保存在本机或 WebDAV。支持定时备份、精细恢复和恢复前安全快照；凭据默认不入库，运行时零依赖。

English: Whale Girl Backup packs dsh chat history, plugins, plugin data, settings and optional project files into a SHA-256-verified archive on disk or WebDAV. It adds scheduled backups, selective restore and a pre-restore safety snapshot. Credentials are excluded by default; zero runtime dependencies.
